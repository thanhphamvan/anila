# Security

Report suspected vulnerabilities privately to Van-Thanh Pham at
[code@thanhpv.me](mailto:code@thanhpv.me), or
[phamthanh_cis60@outlook.com](mailto:phamthanh_cis60@outlook.com).
Include affected versions, impact, reproduction steps and a minimal proof
of concept. Do not include live credentials or publish an exploit in a
public issue before the maintainer has had an opportunity to investigate.
No response-time or long-term support commitment is currently offered.

anila provides shell access to machines you pair. Cloudflare terminates TLS
and relays terminal frames; this is not end-to-end encrypted against the
Cloudflare account or runtime. A compromised Worker deployment can affect
terminal access. Protect the Cloudflare account, deployment tokens and host
signing keys. Passkeys, machine signatures and per-account authorization are
required in production. Development authentication bypass is localhost-only.

Machine members can attach to all of that machine's tmux sessions, including
sessions that switched to another Unix account. Use separate machines for
untrusted people. This edition supports new deployments and rejects the
private IdP-era schema; it does not migrate IdP identities or ownership.
